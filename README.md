# Idol Talk · 爱豆英语陪练

> **把 132 位真实 K-pop 爱豆「请」进你的手机，用她/他自己的声音陪你练英语。**

Idol Talk 是一个 **AI 角色陪练应用**：每位爱豆都有**自己的脸、自己的声音（逐人音色克隆）、自己的人设、对你的记忆**。
不是又一个聊天机器人 —— 而是**让 AI「活」起来**在语言学习与情感陪伴场景的一次完整落地。

<p align="center">
  <b>纯前端 PWA</b> · 零框架零构建 · 双击即可运行 · 可自托管后端 · 全栈开源
</p>

## 🚀 快速开始

### 1. 直接跑起来（零依赖）

前端是**纯静态 PWA**，直接打开即可：

```bash
# 方式一：双击 app/index.html（file:// 直接可跑）

# 方式二：起个静态服务（推荐，PWA 可安装）
cd app
python -m http.server 8899
# 浏览器打开 http://127.0.0.1:8899/
```

> 💡 **带语音运行**：需要本地/云端 TTS 服务（见下）。不启服务也能用 —— 对话正常，仅无语音。

### 2. 启用语音（可选）

```bash
cd tts
pip install -r requirements.txt          # 见 requirements.txt
python tts_server.py                     # 启动 OpenAI 兼容 TTS 代理（默认 8780）
```

然后在应用的「我的 → 对话接口 / 配音接口」填入地址即可。

- **本地引擎**：GPT-SoVITS（免费、音色最像，CPU 可跑）
- **云端引擎**：阿里 CosyVoice / MiniMax / 火山（快，按量付费）
- 引擎与密钥**全部在服务端**，前端不接触密钥

### 3. 采集自己的素材（可选）

仓库内置完整的**素材生产管线**（`crawler/` + `tts/`），可自动化产出干净参考音频：

```bash
cd crawler
python fetch_bilibili.py --only bts-j-hope --per-idol 5   # B站抓英语采访
# 或 fetch_idol_voices.py（抖音） / fetch_weibo.py（微博图片）
```

## 🔬 素材管线：让 132 位爱豆「每人一把自己的声音」

本项目最有价值的工程部分 —— 一套**带客观质量闭环**的自动化素材生产线：

```
抓取 → 切片 → 质检 → 降噪 → 转写 → 入库 → 缓存失效
```

**自研质检指标**（把"主观听感"变成"可测量指标"）：

| 指标 | 用途 | 原理 |
|---|---|---|
| **F0 性别检测** | 防止男爱豆素材混入女声旁白 | 自相关基频估计 |
| **BGM 检测** | 防止带伴奏视频克隆出"电音" | 包络调制率(2–8Hz 音节节奏) + 低频能量 + 词间静音抬升 |
| **连续英语过滤** | **保证克隆能说清英语**（关键发现）| Whisper 转写 + 英文占比 ≥ 阈值 |
| **可懂度测试** | 客观衡量"能不能听懂" | 合成固定句 → Whisper 回听 → 词级相似度 |

**实测成效**（128 位样本）：

- 可懂度（≥0.7 判"听得清"）：**45 → 93 位**
- 背景音乐污染：**12 → 0 位**

> 核心洞察：**参考音频的语言决定了克隆能否说清英语** —— 用韩语素材克隆，模型说英语就会崩。
> 因此确立了「素材必须是连续英语」的准入规则，使整体可懂度翻倍。
